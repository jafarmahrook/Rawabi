# دقيقة الفرح - روابي فرح

لعبة ويب تجريبية مخصصة لعرض فكرة بوث روابي فرح على جهاز لوحي أفقي.

## التشغيل

```bash
npm install
npm run dev
```

افتح الرابط المحلي الذي يظهر في الطرفية، غالبًا:

```text
http://localhost:5173/
```

## نسخة العرض

```bash
npm run build
npm run preview
```

## طريقة اللعب

- يدخل اللاعب اسمه فقط.
- لديه 60 ثانية لاختيار المكونات الصحيحة لكل منتج.
- كل منتج مكتمل يرفع النقاط والسلسلة.
- الأخطاء تخصم ثانية واحدة وتكسر السلسلة.
- أفضل النتائج تحفظ محليًا على نفس الجهاز.

## ملاحظة العرض

زر **إدارة** يمسح النتائج المحلية عند الحاجة أثناء التجارب.
