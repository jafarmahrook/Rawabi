# دقيقة الفرح - روابي فرح

لعبة ويب تجريبية مخصصة لعرض فكرة بوث روابي فرح على جهاز لوحي أفقي.

## التشغيل

```bash
npm install
npm run dev
```

افتح الرابط المحلي الذي يظهر في الطرفية، غالبًا:

```text
http://localhost:5173/
```

## نسخة العرض

```bash
npm run build
npm run preview
```

## النشر والمشاركة (مهم)

عند مشاركة اللعبة مع الآخرين **لا تشارك رابط `localhost` أو خادم التطوير** (`npm run dev`)،
لأنه يعمل فقط على جهازك وعلى شبكتك المحلية، ولهذا تظهر رسالة *"can't reach this page"*
وتحتاج لإعادة التحميل عدة مرات.

شارك دائمًا **رابط الإنتاج الثابت من Vercel**. المشروع مرتبط مسبقًا بـ Vercel، والنشر:

```bash
npm run build
npx vercel --prod
```

بعد النشر سيظهر رابط `*.vercel.app` ثابت يعمل من أول مرة لأي شخص ومن أي جهاز.

## طريقة اللعب

- يدخل اللاعب اسمه فقط.
- لديه 60 ثانية لاختيار المكونات الصحيحة لكل منتج.
- كل منتج مكتمل يرفع النقاط والسلسلة.
- الأخطاء تخصم ثانية واحدة وتكسر السلسلة.
- أفضل النتائج تحفظ محليًا على نفس الجهاز.

## ملاحظة العرض

زر **إدارة** يمسح النتائج المحلية عند الحاجة أثناء التجارب.
